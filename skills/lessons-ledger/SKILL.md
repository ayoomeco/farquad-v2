# Lessons ledger (Reflexion-style)
Stored verbal lessons, re-read before similar work, improve later attempts.
1. Write to memory: date | what happened | root cause | rule for next time.
2. Before similar future tasks, search memory for related lessons.
3. If the same lesson appears twice, draft a skill change and ask the user before applying it.
